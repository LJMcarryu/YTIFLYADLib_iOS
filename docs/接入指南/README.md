# 接入指南

本目录按“安装 → 初始化与隐私 → 广告形式 → 竞价 → 生命周期与排错”的顺序组织。README 只保留快速开始；完整 API 语义以当前版本公开头和下列指南为准。

## 使用顺序

1. 先阅读安装方式，选择 CocoaPods、Swift Package Manager 或手动集成中的一种。
2. 按隐私与网络要求完成宿主授权和请求前配置。
3. 选择实际使用的广告形式，按对应指南接入。
4. 需要竞价时再阅读竞价指南；遇到问题先看生命周期与排错说明。

## 指南目录

- [安装方式](安装方式.md)：CocoaPods、Swift Package Manager 和手动集成
- [隐私与请求配置](隐私与请求配置.md)：隐私、ATT 和请求参数
- [开屏广告](开屏广告.md)：开屏图片/视频加载和展示
- [插屏广告](插屏广告.md)：插屏半屏/全屏加载和展示
- [服务端竞价](服务端竞价.md)：服务端竞价与结果通知
- [生命周期与排错](生命周期与排错.md)：Scene、回调、生命周期和排错

## 发布与版本

- 当前版本和正式 Release 以根目录 `release-state.json`、README 发布标记和同版本 TOS 发布记录 为准。
- 发布历史见[历史发布记录](../需求设计/发布验收/历史发布记录.md)。
- 安装示例固定到明确版本；升级前先阅读根目录 `CHANGELOG.md`。
