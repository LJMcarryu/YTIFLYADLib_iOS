# 优推 YT SDK 安装方式

适用于本仓库 SDK `6.5.0`。API 以所安装版本的 framework 公开头为准。

[接入概览](../../README.md)

同一 App 选择 CocoaPods、Swift Package Manager 或 TOS 手动集成中的一种，避免重复链接 SDK 或重复拷贝资源。

## CocoaPods

在 App 的 `Podfile` 中添加：

```ruby
source 'https://cdn.cocoapods.org/'
platform :ios, '11.0'

target 'YourApp' do
  use_frameworks!
  pod 'YTIFLYADLib', '6.5.0'
end
```

将 `YourApp` 改为实际 target 名称，然后执行：

```bash
pod install
open YourApp.xcworkspace
```

CocoaPods 会处理 `YTAdvSDK.bundle`、`-ObjC`、`AdSupport` 和弱链接的 `AppTrackingTransparency`。后续从 `.xcworkspace` 打开工程。当前通过 CocoaPods 官方 trunk 分发，直接使用 Pod 名称和固定版本安装。

## Swift Package Manager

在 Xcode 中选择 **File > Add Package Dependencies…**，输入公开仓地址：

[https://github.com/LJMcarryu/YTIFLYADLib_iOS.git](https://github.com/LJMcarryu/YTIFLYADLib_iOS.git)

版本选择 **Exact Version** `6.5.0`，将 **YTIFLYADLib** Product 添加到 App target。

GitHub 提供包清单、资源与版本 Tag，TOS 提供二进制下载，不需要 GitHub Release。仓库中的 `Package.swift` 负责声明产品、资源和校验值；实际 XCFramework 由 TOS 地址提供。

SwiftPM 或手动集成时，在最终 App target 的 **Other Linker Flags** 中保留 `$(inherited)` 并添加：

```text
-ObjC
```

在 App target 的 **Link Binary With Libraries** 中加入 `AdSupport.framework`，将 `AppTrackingTransparency.framework` 设为 **Optional**。SwiftPM 自动携带 SDK 资源，无需再从手动包重复拷贝。构建后确认 `Package.resolved` 中该仓版本为 `6.5.0`。

## 手动集成

从 [6.5.0 发布记录](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/yt/fast-release-record.json) 下载本版本完整包 `YTIFLYADLib-6.5.0.zip`。资产选择如下：

| 用途 | 资产 | 附加内容 |
| --- | --- | --- |
| 手动接入 | `YTIFLYADLib-6.5.0.zip` | 包含 framework 与资源，按下列步骤集成 |
| SwiftPM 二进制 | `YTIFLYADLib.xcframework.zip` | 由 `Package.swift` 配合资源 target 使用，不作为手动完整包 |
| 校验下载 | `checksums.txt` | 与同版 TOS 下载文件核对 |

解压完整包后：

1. 将 `YTIFLYADLib.xcframework` 加入 App target 的 **Frameworks, Libraries, and Embedded Content**，选择 **Do Not Embed**。
2. 将 `YTAdvSDK.bundle` 加入 App target 的 **Copy Bundle Resources**，保留包目录名称和内容。
3. 在 **Other Linker Flags** 中保留 `$(inherited)`，添加 `-ObjC`。
4. 确认 App 已链接 `AdSupport.framework`；将 `AppTrackingTransparency.framework` 以 **Optional** 方式链接，以兼容 iOS 11～13。
5. 导入伞头，编译并确认最终 App 包中包含资源及隐私清单。

本版完整包：[下载 YTIFLYADLib-6.5.0.zip](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/yt/YTIFLYADLib-6.5.0.zip)。
